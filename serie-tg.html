Ventajas de la Serie TG

  • Una sola unidad puede admitir el control de hasta 128 zonas.
  • Con la función de detección de fallas en línea, el equipo funciona de manera estable.
  • Sistema estable de una tarjeta, un control.
  • La configuración de parámetros es sencilla y el equipo es estable y confiable.

El primer módulo de control de temperatura operado con perilla

Cuando no se utiliza la pantalla táctil, la temperatura y otras funciones se pueden ajustar girando la perilla del módulo de control de temperatura local. La pantalla LCD del módulo de control de temperatura local, con visualización completa en chino/inglés, muestra el número de serie del control de temperatura, el tipo de termopar, la corriente, la proporción de salida de corriente, el estado de funcionamiento y la información de fallos. El panel cuenta con perillas de operación, indicadores luminosos de estado de alimentación y de comunicación, y el módulo de control de temperatura se puede intercambiar entre cualquier zona de control de temperatura.
